# Regras de Negócio (RN)

| Código | Descrição |
|--------|-----------|
| RN01 | Somente pessoas maiores de 18 anos podem finalizar uma reserva, conforme informado no cadastro (data de nascimento). |
| RN02 | A conferência final da maioridade é feita presencialmente, com documento com foto, no momento da retirada. O cadastro no site é uma pré-validação, não uma comprovação legal. |
| RN03 | Toda reserva não retirada em até 24 horas após o horário combinado expira automaticamente e o estoque reservado retorna ao estoque disponível. |
| RN04 | O pagamento é realizado exclusivamente no momento da retirada, no estabelecimento. |
| RN05 | Não é permitido reservar uma quantidade maior do que o estoque disponível do produto. |
| RN06 | Toda alteração de estoque (entrada, saída, reserva ou ajuste) deve ser registrada no histórico de movimentações, não sendo permitida alteração direta do saldo sem rastro. |
| RN07 | Somente o administrador (dono do estabelecimento) pode cadastrar produtos, alterar preços e registrar entrada/saída manual de estoque. |
| RN08 | Dados pessoais dos clientes (CPF, data de nascimento) são utilizados apenas para validação de maioridade e identificação da reserva, conforme a LGPD, não sendo compartilhados com terceiros. |
| RN09 | Um produto com estoque zerado não pode ser reservado, mas continua visível no catálogo como "indisponível". |
