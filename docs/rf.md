# Requisitos Funcionais (RF)

| Código | Descrição |
|--------|-----------|
| RF01 | O sistema deve permitir que o cliente visualize o catálogo de produtos disponíveis, com nome, categoria, preço, volume e foto. |
| RF02 | O sistema deve permitir que o cliente crie uma conta informando nome, e-mail, CPF e data de nascimento. |
| RF03 | O sistema deve permitir que o cliente reserve um ou mais produtos para retirada no estabelecimento. |
| RF04 | O sistema deve gerar um status para cada reserva (pendente, pronta para retirada, retirada, expirada, cancelada). |
| RF05 | O sistema deve permitir que o cliente acompanhe o status de suas reservas. |
| RF06 | O sistema deve permitir que o cliente cancele uma reserva antes da retirada. |
| RF07 | O sistema deve permitir login exclusivo para o administrador (dono da Adega do Rei), com permissões diferentes das do cliente. |
| RF08 | O sistema deve permitir que o administrador cadastre novos produtos. |
| RF09 | O sistema deve permitir que o administrador edite informações de um produto existente. |
| RF10 | O sistema deve permitir que o administrador registre entrada de estoque (compra de fornecedor). |
| RF11 | O sistema deve permitir que o administrador registre saída de estoque manual (perda, vencimento, quebra). |
| RF12 | O sistema deve permitir que o administrador visualize e gerencie as reservas recebidas (confirmar, marcar como retirada, cancelar). |
| RF13 | O sistema deve manter um histórico de todas as movimentações de estoque (entrada, saída, reserva, ajuste). |
| RF14 | O sistema deve emitir um alerta ao administrador quando o estoque de um produto atingir um nível mínimo configurado. |
| RF15 | O sistema deve impedir que uma reserva seja concluída caso o produto esteja com estoque insuficiente. |
